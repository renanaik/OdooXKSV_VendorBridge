# VendorBridge

VendorBridge is a centralized Procurement & Vendor Management ERP that digitizes the complete procurement lifecycle.

## Project Structure

- `/frontend` - Next.js App Router (React, Tailwind, shadcn/ui)
- `/backend` - API services (To be implemented)
- `/docs` - Documentation
- `/assets` - Static assets and mock data

## Getting Started

To run the frontend:

```bash
cd frontend
npm run dev
```
